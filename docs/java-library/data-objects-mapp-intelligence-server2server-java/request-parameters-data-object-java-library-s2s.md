# Request Parameters

> Based on the public documentation <https://docs.mapp.com/docs/request-parameters-data-object-java-library-s2s> (retrieved 2026-09-29), updated to the current code of this repository.

This page explains all query parameters used in Mapp Intelligence tracking requests. It provides a consolidated reference of parameter names, their meanings, data types, and required status.

Each parameter corresponds to a specific field in the Mapp Intelligence data model and can be transmitted directly, for example in **server-to-server** requests or when validating Smart Pixel implementations.

> [!NOTE]
> The object-specific pages (e.g., Page, Order, Session, User) describe the concepts and configuration details.
>
> This reference focuses on the exact parameter names (such as pn, ov, or uc700) that appear in tracking requests.

Typical use cases include:

- Validating and debugging tracking requests.
- Mapping SDK methods (e.g. setValue, setId) to corresponding query parameters.
- Comparing tracking payloads across implementation types.

> [!NOTE]
> **How `MappIntelligenceParameterMap` requests are built** (`MappIntelligenceTracking.track(MappIntelligenceParameterMap)`):
>
> - All names are available as constants in `MappIntelligenceParameter`; the numbered custom parameters are built with `MappIntelligenceCustomParameter.<NAME>.with(id)`.
> - Keys and values are sent exactly as you add them (only URL-encoded). `add(key, value)` with a `null` key or value is ignored. Unlike the data objects, empty values and `"0"`, `"0.0"` or `"false"` are **not** removed, and nothing is validated or converted (e.g. product statuses, boolean values).
> - The convenience logic of the data objects does not apply: `setTemporarySessionId` also sends `fpt`, a campaign object resolves media codes and *once per session*, a registration object requires `setOptIn(true)`, and the Engage object builds and escapes the `eaj` JSON. With a parameter map you have to do this yourself.
> - `pn` is not sent as its own parameter; its value becomes the page name in the mandatory `p` parameter. Without `pn` the library builds a default page name from the request URL.
> - The library adds the parameters described under [General](#general). It overwrites your values for `eid`, `X-WT-IP`, `X-WT-UA`, the client hints and `pu` (if it knows a value for them) as well as for `pf`, `cs801`, `cs802` and `pec` (when advanced permission is activated).

## General

| **Parameter** | **Description** | **Type** | **Supported Request Type** | **Required** | **Example** |
|---|---|---|---|---|---|
| **p** (no constant) | Mandatory pixel parameter, built by the library: `600,<page name>,,,,,<timestamp>,<referrer>,,`. The page name comes from `pn` (or the default page name), the referrer from `MappIntelligenceConfig.setReferrerURL` (`0` = none, `1` = one of your own domains). | String | page / event | ✓ | "600,en.home,,,,,1727600000000,0,," |
| **EVER_ID (eid)** | Unique long-term visitor identifier. Set automatically by the library from the cookies `wtstp_eid` (Smart Pixel), `wteid_<track ID>` (server-side cookie) or `wt3_eid` (Pixel v4/v5), or generated by `getUserIdCookie(String pixelVersion, String context)`. Not sent while no ID is known. | String | page / event | ✓ | "1234567890123456789" |
| **CUSTOM_EVER_ID (ceid)** | Custom visitor identifier, if your own user ID is used instead of the system-generated eid. | String | page / event | – | "098f6bcd4621d373cade4e832627b4f6" |
| **ADVANCED_PERMISSION_CATEGORY (pec)** | Enable if you need to differentiate between additional usage options for the tracked data, e.g., only to your Intelligence instance or to both Intelligence and Engage.<br>- 0 (default): only Intelligence<br>- 3: Intelligence and Engage<br>Added by the library only when `MappIntelligenceConfig.setActivateAdvancedPermission(true)` is set, with the value of `setAdvancedPermissionCategory` (not validated). | Number | page / event | - | 0 |
| **USER_AGENT (X-WT-UA)** | Original client user agent string (optional, only relevant for server-side tracking). Added automatically from `MappIntelligenceConfig.setUserAgent`. | String | page / event | – | "Mozilla/5.0 (X11; Ubuntu; Linux x86_64; rv:82.0) Gecko/20100101 Firefox/82.0" |
| **USER_IP (X-WT-IP)** | Original client IP address (optional, only relevant for server-side tracking). Added automatically from `MappIntelligenceConfig.setRemoteAddress`. | String | page / event | – | "127.0.0.1" |
| **CLIENT_HINT_USER_AGENT (X-WT-SEC-CH-UA)** | User-agent client hint `Sec-CH-UA`. Added automatically from `MappIntelligenceConfig.setClientHintUserAgent`. | String | page / event | – | "\"Chromium\";v=\"128\", \"Google Chrome\";v=\"128\"" |
| **CLIENT_HINT_USER_AGENT_FULL_VERSION_LIST (X-WT-SEC-CH-UA-FULL-VERSION-LIST)** | Client hint `Sec-CH-UA-Full-Version-List`, from `setClientHintUserAgentFullVersionList`. | String | page / event | – | "\"Chromium\";v=\"128.0.6613.120\"" |
| **CLIENT_HINT_USER_AGENT_MODEL (X-WT-SEC-CH-UA-MODEL)** | Client hint `Sec-CH-UA-Model`, from `setClientHintUserAgentModel`. | String | page / event | – | "\"Pixel 8\"" |

| **CLIENT_HINT_USER_AGENT_PLATFORM_VERSION (X-WT-SEC-CH-UA-PLATFORM-VERSION)** | Client hint `Sec-CH-UA-Platform-Version`, from `setClientHintUserAgentPlatformVersion`. | String | page / event | – | "\"15.0.0\"" |
| **PAGE_URL (pu)** | URL of the current request, added automatically from `MappIntelligenceConfig.setRequestURL`, with the protocol of the request URL (`http://` or `https://`). | String | page / event | – | "https://www.example.com/shop?id=1" |
| **PIXEL_FEATURES (pf)** | Internal usage statistics of the library. Always set by the library. | String | page / event | – | – |
| **VERSION (cs801)** | Version of the library. Always set by the library. | String | page / event | – | – |
| **TRACKING_PLATFORM (cs802)** | Tracking platform. Always set by the library to `Java`. | String | page / event | – | "Java" |

## Page

**Parameters**

| **Parameter** | **Description** | **Type** | **Supported Request Type** | **Required** | **Example** |
|---|---|---|---|---|---|
| **PAGE_NAME (pn)** | Technical name of the page (used for identification and grouping). | String | page | ✓ | "en.home" |
| **SEARCH (is)** | Search term used in the internal search function. | String | page | – | "running shoes" |
| **NUMBER_SEARCH_RESULTS (cp771)** | Number of search results returned for the entered term. | Number | page | – | 15 |
| **ERROR_MESSAGES (cp772)** | Error message displayed on the page. | String | page | – | "invalid password" |
| **PAYWALL (cp773)** | Indicates a paywall call. Use 1 for true. Note: `MappIntelligencePage.setPaywall(true)` sends the value `true`; `false` is not sent. | Number | page | – | 1 |
| **ARTICLE_TITLE (cp774)** | Title of the displayed article or content item. | String | page | – | "Best Trail Running Shoes" |
| **CONTENT_TAGS (cp775)** | Tags or categories assigned to the content. | String | page | – | "sports, gear" |
| **PAGE_TITLE (cp776)** | Display title of the page (as shown in browser tab or CMS). | String | page | – | "Running Gear 2025" |
| **PAGE_TYPE (cp777)** | Type of the page, e.g. article, category, homepage. | String | page | – | "product page" |
| **PAGE_LENGTH (cp778)** | Indicates the amount of content or reading length category (e.g. short, medium, long). | String | page | – | "long" |
| **DAYS_SINCE_PUBLICATION (cp779)** | Number of days since the article was published. | Number | page | – | 8 |
| **TEST_VARIANT (cp781)** | Name of the A/B test variant shown to the visitor. | String | page | – | "variant B" |
| **TEST_EXPERIMENT (cp782)** | Name of the A/B test experiment. | String | page | – | "checkout-button-color" |
| **CUSTOM_PAGE_PARAMETER (cp&lt;&lt;1–499>>)** | Custom page parameters for additional information (e.g. category, language). | String / Number | page | – | "cp12 = 'EN'" |
| **CUSTOM_PAGE_CATEGORY (cg&lt;&lt;1–499>>)** | Page category or content group assigned to the page. | String / Number | page | – | "cg3 = 'Outdoor'" |

**Example**

```java
MappIntelligenceConfig mic = new MappIntelligenceConfig(
	"111111111111111",
	"analytics01.wt-eu02.net"
);
MappIntelligenceParameterMap mappParameterMap = new MappIntelligenceParameterMap();
mappParameterMap
	.add(MappIntelligenceParameter.PAGE_NAME, "name of a page")
    .add(MappIntelligenceParameter.SEARCH, "search term")
    .add(MappIntelligenceParameter.NUMBER_SEARCH_RESULTS, "15")
    .add(MappIntelligenceParameter.ERROR_MESSAGES, "error message")
    .add(MappIntelligenceParameter.PAYWALL, "1")
    .add(MappIntelligenceParameter.ARTICLE_TITLE, "name of an article")
    .add(MappIntelligenceParameter.CONTENT_TAGS, "name of a content tag")
    .add(MappIntelligenceParameter.PAGE_TITLE, "title of a page")
    .add(MappIntelligenceParameter.PAGE_TYPE, "type of a page")
    .add(MappIntelligenceParameter.PAGE_LENGTH, "large")
    .add(MappIntelligenceParameter.DAYS_SINCE_PUBLICATION, "8")
    .add(MappIntelligenceParameter.TEST_VARIANT, "name of a variant")
    .add(MappIntelligenceParameter.TEST_EXPERIMENT, "name of an experiment")
    .add(MappIntelligenceCustomParameter.CUSTOM_PAGE_PARAMETER.with(1), "parameter 1")
    .add(MappIntelligenceCustomParameter.CUSTOM_PAGE_PARAMETER.with(2), "parameter 2")
    .add(MappIntelligenceCustomParameter.CUSTOM_PAGE_CATEGORY.with(1), "category 1")
    .add(MappIntelligenceCustomParameter.CUSTOM_PAGE_CATEGORY.with(2), "category 2");

try (MappIntelligenceTracking mit = new MappIntelligenceTracking(mic)) {
    mit.track(mappParameterMap);
}
```

## Product

**Parameters**

| **Parameter** | **Description** | **Type** | **Supported Request Type** | **Required** | **Example** |
|---|---|---|---|---|---|
| **PRODUCT_ID (ba)** | Unique product identifier (e.g., SKU or article number). Must not exceed 110 characters. | String | page | ✓ | "product_1234" |
| **PRODUCT_COST (co)** | Product price. If multiple quantities are transmitted, use the total value (not unit price). | Number | page | – | 19.95 |

| **CURRENCY (cr)** | ISO currency code for the product price (e.g., EUR). `MappIntelligenceProduct` has no currency setter; with data objects it is set via `MappIntelligenceOrder.setCurrency`. | String | page | – | "EUR" |
| **PRODUCT_SOLD_OUT (cb760)** | Indicates product availability (1 = sold out, 0 = available). | Number | page | – | 0 |
| **PRODUCT_VARIANT (cb767)** | Variant of the product. | String | page | - | "red" |
| **CUSTOM_PRODUCT_CATEGORY (ca&lt;&lt;1–499>>)** | Product category or grouping (e.g., brand, type). | String / Number | page | – | "ca2 = 'Shoes'" |
| **CUSTOM_PRODUCT_PARAMETER (cb&lt;&lt;1–499>>)** | E-Commerce Parameters for additional product details (e.g., color, size, material). | String / Number | page | – | "cb3 = 'Blue'" |

```java

    .add(MappIntelligenceCustomParameter.CUSTOM_PRODUCT_PARAMETER.with(2), "parameter 2")
	.add(MappIntelligenceCustomParameter.CUSTOM_PRODUCT_PARAMETER.with(15), "parameter 15")
	.add(MappIntelligenceCustomParameter.CUSTOM_PRODUCT_CATEGORY.with(2), "category 2")
```

## Mapp Engage

**Parameters**

| **Parameter** | **Description** | **Type** | **Supported Request Type** | **Required** | **Example** |
|---|---|---|---|---|---|
| **ENGAGE_ATTRIBUTES (eaj)** | Sends user-specific attributes to Mapp Engage as a JSON object. These can be stored as *Custom Profile Attributes* for segmentation and targeting. `MappIntelligenceEngage` serializes every value as a JSON string and escapes keys and values; with a parameter map you pass the finished, valid JSON yourself. | String (JSON) | page / event | – | {"sizeFinderUsed":"true","favBrand":"Acme"} |
| **ENGAGE_EVENT_NAME (ecwen)** | Defines the name of the Engage *Custom Web Event* (e.g., “Size Finder Used”). This can trigger automations in the Whiteboard. | String | page / event | – | "Size Finder Used" |
| **ENGAGE_EVENT_ID (ecwei)** | Alternative to event_name. Refers to the numeric *Custom Web Event ID* defined in Engage. Mainly used for advanced setups. | Number | page / event | – | 101 |

**Example**

```java
MappIntelligenceConfig mic = new MappIntelligenceConfig(
	"111111111111111",
	"analytics01.wt-eu02.net"
);
MappIntelligenceParameterMap mappParameterMap = new MappIntelligenceParameterMap();
mappParameterMap
```

## Mapp Engage User Matching

**Parameters**

> [!NOTE]
> To enable data exchange between Mapp Intelligence and Engage, User Matching must be active.
>
> The minimum requirement for Web Matching is a valid email address (er1).
>
> `MappIntelligenceRegistration` only sends the `er` parameters after `setOptIn(true)`; with a parameter map they are sent as given. Values are not validated. See [Registration](registration-data-object-java-library-s2s.md) for the data object.
>
> The Engage Contact ID (uc701) is exchanged automatically between systems and normally does not appear in web tracking requests.

| **Parameter** | **Description** | **Type** | **Supported Request Type** | **Required** | **Example** |
|---|---|---|---|---|---|
| **REGISTRATION_EMAIL (er1)** | Email address used to identify or create a contact in Engage. Usually transmitted in hashed form; the library sends the value as given and does not hash it. | String | page / event | ✅ | "hash@example.com" |
| **REGISTRATION_FIELDS (er2 – er10)** | Optional registration-related fields:<br>- REGISTRATION_GROUP_ID (er2)<br>- REGISTRATION_MODE (er3)<br>- REGISTRATION_FIRST_NAME (er4)<br>- REGISTRATION_LAST_NAME (er5)<br>- REGISTRATION_GENDER (er6)<br>- REGISTRATION_TITLE (er7)<br>- REGISTRATION_ISO_CODE (er8)<br>- REGISTRATION_ISO_LANGUAGE (er9)<br>- REGISTRATION_TIMEZONE (er10)<br>The exact mapping of these fields depends on your Engage setup. | String / Number | page / event | – | "er2=123", "er3=d", "er4=Anna", "er8=DE", "er9=de", "er10=Europe/Berlin" |
| **EMAIL_RID (uc701)** | Engage Contact ID used for campaign- or app-based user matching. Usually only visible in requests from campaigns or mobile SDKs. | String | page / event | – | "abc123def456" |

**Notes:**

- **MODE values:** c = *Confirmed Opt-in*, d = *Double Opt-in*, o = *Opt-in*. The library has no default: without `setMode`, no `er3` is sent, and Engage then applies its own default (opt-in).
- **GENDER values:** u = *undisclosed*, f = *female*, m = *male*
- Campaign Matching automatically appends uc701 to Engage campaign URLs.
- For Web Matching, tracking the **email (er1)** is sufficient for identification and linking.

**Example**

```java
MappIntelligenceConfig mic = new MappIntelligenceConfig(
	"111111111111111",
	"analytics01.wt-eu02.net"
);
MappIntelligenceParameterMap mappParameterMap = new MappIntelligenceParameterMap();
mappParameterMap
  .add(MappIntelligenceParameter.PAGE_NAME, "registration.page")
  .add(MappIntelligenceParameter.REGISTRATION_EMAIL, "john.doe@example.com")
  .add(MappIntelligenceParameter.REGISTRATION_GROUP_ID, "123")
  .add(MappIntelligenceParameter.REGISTRATION_MODE, "d")
  .add(MappIntelligenceParameter.REGISTRATION_FIRST_NAME, "John")
  .add(MappIntelligenceParameter.REGISTRATION_LAST_NAME, "Doe")
  .add(MappIntelligenceParameter.REGISTRATION_GENDER, "m")
  .add(MappIntelligenceParameter.REGISTRATION_TITLE, "Dr.")
  .add(MappIntelligenceParameter.REGISTRATION_ISO_CODE, "DE")
  .add(MappIntelligenceParameter.REGISTRATION_ISO_LANGUAGE, "de")
  .add(MappIntelligenceParameter.REGISTRATION_TIMEZONE, "Europe/Berlin");

try (MappIntelligenceTracking mit = new MappIntelligenceTracking(mic)) {
    mit.track(mappParameterMap);
}
```
